# shelter_volunteers SBOM (SPDX JSON)

## What Was Scanned
This SBOM was generated by scanning the repository directory for the
`shelter_volunteers` project. No container image or packaged artifact was
available, so this SBOM represents the repository contents and declared
dependencies rather than the final built application.

## Syft Installation
You may install Syft using any official method, such as:

macOS:
    brew install syft

Linux/macOS:
    curl -sSfL https://get.anchore.io/syft | sh -s -- -b /usr/local/bin

Windows:
    winget install Anchore.Syft

Docker (no local install):
    docker run --rm -v "$(pwd)":/src anchore/syft:latest dir:/src -o spdx-json=/src/sbom.json

## Exact Command Used
From the root of the repository:

    syft dir:. -o spdx-json=docs/sbom/shelter_volunteers-sbom.spdx.json

- This SBOM does not represent the final built artifact.
- Some dynamic or runtime dependencies may not appear.

## Reproducing the SBOM
1. Install Syft.
2. Clone the repository.

4. The SBOM will be written to `docs/sbom/shelter_volunteers-sbom.spdx.json`.
